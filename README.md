# 🥘 Pantry — AI Voice Recipe Finder

Discover recipes using ingredients you already have — by voice, in your own language.

🔗 **Live:** https://ai-recipe-finder-ayush.netlify.app/

---

## ✨ Features

- 🎤 **Voice input** in English, Hindi, Kannada & Marwari
- 🔊 **Read aloud** recipes using browser TTS
- 🤖 **AI recipe generation** powered by Google Gemini
- 🌍 **Full multi-language UI** (en/hi/kn/mr)
- 📦 **Pantry management** with recipe suggestions
- 👤 **User auth** (JWT), save recipes, search, filters
- 🌙 **Dark mode** + responsive design

---

## 🛠️ Tech Stack

**Frontend:** HTML, CSS, Vanilla JS, Web Speech API
**Backend:** Node.js, Express, PostgreSQL (Supabase)
**AI:** Google Gemini (`gemini-3.6-flash`)
**Deploy:** Netlify + Render
